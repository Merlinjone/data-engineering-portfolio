# Data Engineering Portfolio Starter Pack 

This repository contains starter source code and implementation steps for the three resume portfolio projects:
1. RetailPulse — Medallion Lakehouse on Databricks
2. Spark Performance and Streaming Lab
3. Automated Databricks Pipeline with Jobs and CI/CD

## tool choices
- Databricks Free Edition for notebook-based development (usage limits apply)
- GitHub for source control
- Public Olist Brazilian e-commerce dataset (download manually from Kaggle; dataset account/download terms may apply)
- Local Python + PySpark for performance/streaming experiments when Databricks features are unavailable
- pytest for unit tests
- GitHub Actions free minutes within GitHub's current plan limits

Official Databricks Free Edition details: https://docs.databricks.com/aws/en/getting-started/free-edition
Free Edition limitations: https://docs.databricks.com/aws/en/getting-started/free-edition-limitations
Declarative Automation Bundles (formerly Asset Bundles): https://docs.databricks.com/aws/en/dev-tools/bundles/
